# Module 2: Website Request & Requirements Gathering System

## Complete Project Prompt

Create a comprehensive website request and requirements gathering system for Site Iguana. This module allows customers to submit detailed website requests through an intuitive wizard-style interface, providing all the information needed to build their custom websites.

## Project Overview

Site Iguana customers need an easy way to communicate their website needs, preferences, and requirements. This module captures everything from basic business information to design preferences, content requirements, and special features through a guided, user-friendly process.

## Core Features Required

### 1. Website Request Wizard
- **Multi-Step Process**: 5-step wizard that guides users through requirements gathering
- **Progress Tracking**: Visual progress bar showing current step and completion
- **Save & Resume**: Ability to save progress and continue later
- **Step Validation**: Ensure required information is provided before proceeding
- **Review Summary**: Final step showing all collected information for confirmation

### 2. Business Information Collection
- **Company Details**: Business name, type, description, target audience
- **Contact Information**: Primary contact, phone, email, address
- **Business Goals**: What they want the website to accomplish
- **Target Market**: Who they're trying to reach
- **Unique Value Proposition**: What makes them different

### 3. Design Preferences & Style
- **Visual Style Selection**: Modern, classic, creative, professional, etc.
- **Color Scheme Preferences**: Favorite colors, brand colors, color psychology
- **Layout Preferences**: Single page, multi-page, sidebar, full-width options
- **Font Preferences**: Serif, sans-serif, script, modern font styles
- **Reference Websites**: Upload screenshots or URLs of liked websites

### 4. Content & Functionality Requirements
- **Required Pages**: About, services, contact, blog, gallery, etc.
- **Special Features**: Contact forms, booking systems, e-commerce, galleries
- **Content Status**: What content they have ready vs. what needs to be created
- **Image Requirements**: Professional photos, stock images, logo needs
- **Social Media Integration**: Which platforms to connect

### 5. Technical Specifications
- **Domain Information**: Existing domain or need new domain registration
- **Hosting Preferences**: Any specific hosting requirements
- **Email Setup**: Professional email needs
- **Analytics**: Google Analytics, Facebook Pixel, other tracking needs
- **SEO Requirements**: Target keywords, local SEO needs

### 6. Timeline & Budget Planning
- **Launch Timeline**: Desired completion date, any hard deadlines
- **Budget Range**: Investment level for website development
- **Priority Features**: Must-have vs. nice-to-have features
- **Phased Approach**: Possibility of launching in phases

## User Interface Requirements

### Design Style
- **Wizard Interface**: Clean, step-by-step process with clear navigation
- **Visual Elements**: Icons, progress indicators, and helpful illustrations
- **Mobile Optimized**: Perfect experience on all devices
- **Professional Appearance**: Matches Site Iguana branding and quality

### Wizard Steps Interface
1. **Step 1: Business Information**
   - Company name, industry, description
   - Target audience and business goals
   - Contact information collection

2. **Step 2: Design & Style Preferences**
   - Style selection with visual examples
   - Color palette chooser
   - Layout preference options
   - Reference website collection

3. **Step 3: Content & Pages**
   - Page requirements checklist
   - Feature selection interface
   - Content readiness assessment
   - Media requirements planning

4. **Step 4: Technical Requirements**
   - Domain and hosting preferences
   - Integration requirements
   - SEO and analytics setup
   - Email configuration needs

5. **Step 5: Review & Submit**
   - Complete summary of all selections
   - Edit options for each section
   - Final submission with confirmation

### Visual Components
- **Progress Bar**: Shows completion percentage and current step
- **Section Cards**: Organized information collection in card format
- **Image Upload**: Drag-and-drop areas for logos and reference images
- **Interactive Elements**: Clickable options, checkboxes, and radio buttons
- **Help Text**: Tooltips and explanations throughout the process

## Functional Requirements

### Request Management Flow
1. **Request Creation**:
   - User starts new website request
   - Wizard guides through all required information
   - System saves progress automatically
   - User can pause and resume at any time

2. **Content Collection**:
   - Comprehensive business information gathering
   - Design preference documentation
   - Technical requirements specification
   - Timeline and budget planning

3. **Review Process**:
   - Complete summary of all provided information
   - Ability to edit any section before submission
   - Final confirmation and submission
   - Automatic notification to admin team

4. **Status Tracking**:
   - Real-time status updates on request progress
   - Notification system for status changes
   - Communication channel with development team
   - Timeline tracking and milestone updates

### Admin Review System
1. **Request Dashboard**: View all incoming website requests
2. **Detailed Review**: Complete information display for each request
3. **Status Management**: Update request status and add notes
4. **Client Communication**: Send updates and ask clarifying questions
5. **Project Planning**: Convert approved requests into project plans

### File & Media Management
1. **Logo Upload**: Secure upload and storage of company logos
2. **Reference Images**: Collection of design inspiration images
3. **Content Documents**: Upload of existing content and materials
4. **Brand Assets**: Collection of existing marketing materials
