# Module 5: User Dashboard & Account Management System

## Complete Project Prompt

Create a comprehensive user dashboard and account management system for Site Iguana customers. This module serves as the central hub where users manage their website projects, track progress, handle billing, communicate with the team, and access all account-related features.

## Project Overview

Site Iguana customers need a professional, intuitive dashboard where they can monitor their website projects, manage their account, handle billing and payments, communicate with the development team, and access support resources. This dashboard should feel like a premium service interface that reflects Site Iguana's quality and professionalism.

## Core Features Required

### 1. Dashboard Overview & Navigation
- **Welcome Dashboard**: Personalized greeting with account status overview
- **Project Summary Cards**: Visual summary of all website projects and their status
- **Quick Actions**: Fast access to common tasks like requesting changes or viewing invoices
- **Notification Center**: Important updates, messages, and alerts
- **Navigation Menu**: Intuitive navigation to all account features
- **Recent Activity**: Timeline of recent account and project activities

### 2. Website Project Management
- **Project Status Tracking**: Real-time status of website development projects
- **Progress Visualization**: Visual progress bars and milestone tracking
- **Project Details**: Complete project information, requirements, and specifications
- **Timeline View**: Project timeline with milestones and expected completion dates
- **File Access**: Access to project deliverables, designs, and assets
- **Communication History**: Complete history of project communications

### 3. Account Information Management
- **Profile Management**: Update personal and company information
- **Contact Information**: Manage contact details and preferences
- **Security Settings**: Password changes and account security options
- **Notification Preferences**: Control email and system notifications
- **Account Status**: View account standing and service status
- **Support Access**: Easy access to help and support resources

### 4. Billing & Payment Management
- **Current Subscription**: View active subscription plan and details
- **Payment Methods**: Manage saved payment methods securely
- **Billing History**: Complete payment history with downloadable receipts
- **Invoice Access**: View and download invoices and statements
- **Plan Management**: Upgrade, downgrade, or modify service plans
- **Payment Issues**: Handle payment problems and update billing information

### 5. Communication & Support Center
- **Message Center**: Secure communication with Site Iguana team
- **Support Tickets**: Create and track support requests
- **Change Requests**: Submit website modification requests
- **Feedback System**: Provide feedback on services and projects
- **Knowledge Base**: Access to help articles and documentation
- **Live Chat Integration**: Real-time support when available

### 6. Service Management
- **Website Services**: Manage ongoing website services and features
- **Performance Monitoring**: Basic website performance metrics
- **Domain Management**: View domain information and renewal dates
- **Service Requests**: Request additional services or modifications
- **Maintenance Schedule**: View scheduled maintenance and updates
- **Service History**: Complete history of services provided
