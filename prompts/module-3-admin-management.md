# Module 3: Admin Project Management System - Complete Prompt

Build a comprehensive admin dashboard for Site Iguana that allows administrators to manage website requests, track projects, communicate with clients, and oversee the entire website creation process.

## Project Overview
This module provides administrators with tools to review incoming website requests, manage project workflows, track progress, and maintain client relationships throughout the website development process.

## Core Features Required

### 1. Admin Dashboard
- Overview of all active projects and metrics
- Quick stats (pending requests, active projects, completed sites)
- Recent activity feed
- Urgent items requiring attention
- Performance metrics and charts
- Quick action buttons for common tasks

### 2. Request Management
- List all incoming website requests
- Filter and sort by status, date, client, budget
- Detailed request view with all client information
- Approve/reject functionality with notes
- Batch operations (approve multiple, assign to team member)
- Request priority setting

### 3. Project Workflow Management
- Project status tracking (pending → approved → in development → review → completed → live)
- Assign projects to team members
- Set project timelines and milestones
- Progress tracking with percentage completion
- Project notes and internal comments
- File and asset management per project

### 4. Client Communication
- Built-in messaging system for client updates
- Email integration for notifications
- Status update notifications to clients
- Request for additional information from clients
- Change request management
- Review and approval workflows

### 5. User Management
- View all registered users
- User account details and activity
- Upgrade/downgrade user permissions
- User support ticket management
- Account status management (active, suspended, etc.)

## Functional Specifications

### Request Processing Workflow
1. New request appears in "Pending Review" queue
2. Admin reviews all request details
3. Admin can request clarification from client
4. Admin approves with project plan or rejects with reason
5. Approved requests move to "Ready to Start"
6. Projects are assigned to team members
7. Progress is tracked through development phases

### Project Status Management
- **Pending Review**: New requests awaiting admin review
- **Approved**: Requests approved and ready to start
- **In Development**: Active development phase
- **Client Review**: Waiting for client feedback
- **Revisions**: Making requested changes
- **Completed**: Project finished and ready for launch
- **Live**: Website is live and in maintenance mode
