# Module 6: Public Marketing Website - Complete Prompt

Build a comprehensive public marketing website for Site Iguana that showcases services, attracts new customers, and converts visitors into paying clients for the website creation platform.

## Project Overview
Create a high-converting marketing website that serves as the public face of Site Iguana, educating visitors about custom website services, showcasing portfolio work, and guiding prospects through the customer acquisition funnel.
