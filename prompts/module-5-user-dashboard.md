# Module 5: User Dashboard & Client Portal - Complete Prompt

Build a comprehensive user dashboard and client portal for Site Iguana that allows customers to manage their website projects, track progress, communicate with the team, and handle their account settings.

## Project Overview
This module creates the primary interface where Site Iguana customers manage their website projects, view progress, communicate with the development team, manage their subscriptions, and access all account-related features.

## Core Dashboard Features

### 1. Main Dashboard Overview
- Welcome message with personalized greeting
- Quick stats overview (active projects, completed sites, subscription status)
- Recent activity feed
- Upcoming milestones and deadlines
- Quick action buttons (new website request, contact support, view billing)
- Progress indicators for current projects

### 2. Project Management
- List of all website requests and projects
- Project status tracking with visual indicators
- Detailed project views with timeline
- Progress photos and updates from development team
- Project milestone tracking
- Estimated completion dates

### 3. Communication Center
- Message thread with development team
- Project-specific communications
- File sharing capabilities
- Change request submission
- Feedback and review submission
- Support ticket system

### 4. Billing & Subscription Management
- Current subscription plan display
- Payment method management
- Billing history and invoices
- Plan upgrade/downgrade options
- Usage tracking (for plans with limits)
- Payment notifications and alerts
